#Kukaiņu ēdājs

Mērķis: apēst 5 kukaiņus, un neapvemties.

Spēlētājs: iesācējs, kuram pirms spēles vajadzīgi īsi noteikumi.

## Atvēršana
Lejupielādē projektu no GitHub: Code → Download ZIP.
Izpako ZIP un atver index.html pārlūkā.

## Pārbaudes
- Atveru index.html: redzams sākums, laukums paslēpts.
- Nospiežu “Sākt spēli”: redzams laukums, sākums paslēpts.
- Nospiežu “Atpakaļ”: redzams sākums, laukums paslēpts.

## Atsauksme
Klasesbiedrs smējās un priecājās par manis radīto spēli, bet nesaprata punktu iegūšanu.
Precizēju pirmo noteikumu: viena kukaiņa apēšana ir kaa dabuut 1 puntku.
Atkārtotajā pārbaudē klasesbiedrs punktu iegūšanu izskaidroja pareizi.
